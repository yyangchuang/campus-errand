## 一、产品定位

| 项 | 内容 |
|---|---|
| **是什么** | 大学校园内，同学之间互助代取快递的微信小程序 |
| **解决什么** | 上课/宅寝/下雨懒得动 → 快递驿站排队远 → 花钱请同学代跑 |
| **和闪送/UU 区别** | 校园内闭环、同校可信、价格便宜（3~10 元）、学生对学生 |
| **用户画像** | 发单者：任何嫌取快递麻烦的同学；跑腿者：想赚点零花钱的同学 |
| **一句话介绍** | 宿舍躺平，有人帮你把快递送到手 |

## 二、核心业务流程

```
① 发单用户                              ② 跑腿者
┌─────────────┐                    ┌─────────────┐
│ 填快递信息   │                    │ 看到新订单    │
│ 填送达地址   │   订单进入大厅      │ 点"立即接单"  │
│ 设跑腿费     │ ─────────────────▶ │              │
│ 发布 ✅      │                    │ 收到通知      │
└─────────────┘                    └──────┬──────┘
                                          │
                                          ▼
                               ┌─────────────────────┐
                               │ ③ 跑腿者去驿站取件    │
                               │    （可拍照凭证）      │
                               └──────────┬──────────┘
                                          │
                                          ▼
                               ┌─────────────────────┐
                               │ ④ 送到发单者宿舍楼下  │
                               │    发单者下楼签收      │
                               └──────────┬──────────┘
                                          │
                                          ▼
                               ┌─────────────────────┐
                               │ ⑤ 发单者确认签收       │
                               │   → 跑腿费自动结算    │
                               │   → 可选给个好评 ⭐    │
                               └─────────────────────┘
```

## 五、订单状态机（P0 简化版）

```
待接单 ──跑腿者点"接单"──▶ 取件中 ──点"已取件"──▶ 运送中 ──点"已送达"──▶ 已送达 ──发单者点"签收"──▶ 已完成
  │                                                                                                     ▲
  └──── 发单者点"取消" ───────────────────────────────────────────────────────────────────────────────▶ 已取消
```

### 状态 × 角色 操作矩阵

| 当前状态 | 发单用户能做 | 跑腿者能做 |
|---|---|---|
| 待接单 | 取消订单 | 立即接单 |
| 取件中 | 取消订单 / 联系跑腿 | 点"已取件" / 联系发单 |
| 运送中 | 联系跑腿 | 点"已送达" / 联系发单 |
| 已送达 | 点"确认签收" | 等发单者签收 |
| 已完成 | —— | —— |
| 已取消 | —— | —— |

## 六、UI 风格建议

| 项 | 建议 | 备注 |
|---|---|---|
| **主色调** | 待定，从以下选一个 | ① 活力橙 `#ff6b35` ② 校园绿 `#2e7d32` ③ 快递蓝 `#1976d2` ④ 粉嫩紫 `#7c4dff` |
| **整体风格** | 简洁、大圆角、卡片化 | 类小红书 / 抖音风，大学生审美 |
| **字体** | 微信默认 PingFang SC | 不引入额外字体 |
| **图标** | 先 Emoji 过渡，后期换 iconfont | 快速迭代 |
| **圆角规范** | 卡片 16~20rpx，按钮 48rpx 胶囊 | 统一视觉语言 |
| **TabBar 数量** | 4 个 | 大厅 / 发布 / 订单 / 我的 |

## 七、技术选型
